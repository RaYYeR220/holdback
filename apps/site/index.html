    Three commands.

    Holdback installs from source for now. Build it once, then run the three commands in your app’s folder, next to the spec.

    Needs Node 24+ and pnpm 9, git, Kane CLI signed in to your TestMu AI account, and Claude Code. The planted-bug pass also needs a Venice API key.

    Once, in a clone of the repository

    $pnpm i && pnpm -r build

    Install and build every package.

    $cd packages/cli && npm link

    Put holdback on your PATH.

    Then, in your app’s folder

    $holdback init

    Point Holdback at your spec and the command that starts your app.

    $holdback spec

    Answer Kane’s questions, approve the criteria, seal the tests.

    $holdback run

    Build until Kane proves every criterion, then plant bugs and replay.

    Or for your own Claude Code session: holdback init --agent claude installs the hooks.

    What we don’t claim

    Read CLAIMS.md
    • OS-level isolation.The tests sit outside the repo, pinned by hash, with a hook on every agent tool call. That’s a seal, not a sandbox.
    • Private test runs.Kane CLI uploads its runs to LambdaTest Test Manager.
    • A win on the exam.All three builds passed every case. On this spec, Claude Code alone gets there.
    • Real survivors.Every planted bug that got past Kane in the pantry run broke nothing its criterion says. Holdback still counts it, and has Kane rewrite tests.
    • Cheap authoring.In the first live run, Kane charged about 16 credits for each test step it authored. Replays cost 0 to 3 credits, and 17.6 when Kane had to heal one.
